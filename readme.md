# fruits_shop

HTML, CSS, JavaScript를 활용하여 과일 데이터를 화면에 출력하고
사용자의 입력에 따라 데이터를 검색하고 정렬하는 과일 상점 예제 프로젝트입니다.

## 📌 프로젝트 소개

JavaScript에서 배열로 관리되는 과일 데이터를 HTML 테이블에 동적으로 출력하고,
사용자의 검색 및 정렬 조건에 따라 화면의 데이터를 변경하도록 구현했습니다.

JavaScript를 이용한 데이터 처리와 DOM 조작을 학습하는 것을 목표로 했습니다.

## 🛠️ 기술 스택

- HTML
- CSS
- JavaScript

## ✨ 주요 기능

- 과일 목록 동적 출력
- 과일 데이터 검색
- 과일 데이터 정렬
- 사용자 입력 이벤트 처리
- 테이블 데이터 동적 생성
- 이미지 및 과일 정보 출력

## 📚 학습 내용

- JavaScript 배열 데이터 처리
- `filter()`를 이용한 데이터 검색
- `sort()`를 이용한 데이터 정렬
- `map()` 등을 활용한 데이터 가공
- DOM을 이용한 테이블 동적 생성
- `input` 이벤트를 이용한 실시간 검색
- JavaScript에서 HTML 요소를 동적으로 생성하는 방법

## 📝 느낀 점

JavaScript의 배열 메서드를 이용하여 데이터를 가공하고
그 결과를 DOM에 반영하는 과정을 학습했습니다.

특히 사용자의 입력에 따라 데이터를 필터링하고 정렬하는 기능을 구현하면서
JavaScript의 데이터 처리와 이벤트 처리에 대한 이해를 높일 수 있었습니다.
